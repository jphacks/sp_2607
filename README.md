**レシートを撮るだけで、買った物をどの順で、どの袋に詰めればいいかを3Dで先に見せるアプリです。**

## 製品概要
### 背景(製品開発のきっかけ、課題等）
スーパーのサッカー台での袋詰めは、毎回その場の勘に頼っています。

- 重い飲み物を後から入れて、卵が割れたり、パンがつぶれたりする
- 袋が足りなくなる、または大きい袋を買ったのにスカスカになる
- 1つの袋だけ重くなって、持ち手が食い込んだり破れたりする
- 洗剤と食品、肉・魚とほかの食品を同じ袋に入れてしまう

ネットスーパーの荷物を段ボールにまとめるときや、まとめ買いをしたときも同じです。

「何を買ったか」はレシートにすべて書いてあります。それなら、袋に詰める前に詰め方を決められるのではないか、と考えたのがきっかけです。

### 製品説明（具体的な製品の説明）
スマートフォンのブラウザで使うWebアプリです。

1. **レシートを撮る**：長いレシートは2〜3枚に分けて撮れます
2. **袋・箱を選ぶ**：レジ袋 小・中・大、エコバッグ、段ボール 60〜120サイズから選びます。袋や箱の写真を撮れば、写真から大きさを測ることもできます
3. **「詰め方を考える」を押す**

AIがレシートを読み取り、「ｵｲｼｲｷﾞｭｳﾆｭｳ 1000」のような略称を「牛乳 1L」に直します。そのうえで、商品ごとに次を推定します。

- 1個あたりのサイズと重さ
- 扱い方（つぶれやすい・立てる・冷凍／冷蔵・肉魚・日用品）

アプリはその結果から、何袋必要か、どの商品をどの袋のどこに置くかを計算し、3Dで表示します。

### 特長
#### 1. レシートを撮るだけ
商品を1つずつ入力する必要はありません。AIが読み切れなかった商品には「推測」と表示し、サイズや個数をその場で直せます。直すとすぐに詰め直します。

#### 2. 詰める順番を3Dで再生できる
「重い物・立てる物を底に → 箱物で面をそろえる → 軽い物で隙間を埋める → つぶれやすい物を一番上に」の順に、商品が袋へ落ちていく様子を手順ごとに再生します。袋は回転・拡大して見られます。

#### 3. 袋の数と重さが先にわかる
袋ごとの重さと、どこまで詰まるか（高さの割合）を表示します。袋の耐荷重の目安を超えるときは警告し、次の袋に振り分けます。洗剤などの日用品は、自動で食品と別の袋にします。

### 解決出来ること
- 卵・パンがつぶれる、牛乳が倒れてこぼれる、といった袋詰めの失敗を防ぐ
- 必要な袋の数とサイズが事前にわかるので、袋を買いすぎたり、足りなくなったりしない
- 重さが1つの袋に偏らないので、持ち帰りが楽になる
- 食品と日用品、肉・魚とほかの食品を分けられる

### 今後の展望
- **商品データベース**：一度推定した商品のサイズと、利用者が直した値を保存します。次からはAIにレシートを読ませるだけで済むので、結果が安定し、速く、安くなります
- **電子レシートへの対応**：電子レシートのデータを読み込めれば、写真が要らなくなります
- **一般公開**：Claude API経由で動くサーバー（Cloudflare Workers）を用意し、誰でも使えるようにします
- **ARで案内**：手元の袋に、次に入れる商品と置く場所を重ねて表示します

### 注力したこと（こだわり等）
* **問い合わせの量を減らす工夫**：送る前に、ブラウザでレシートの用紙部分だけを切り抜き、白黒化と縮小をします。さらにAIの返答を、キー名なしの短い配列の形にしました。詰め方の計算と3D表示はすべてブラウザの中で行うので、AIへの問い合わせはレシート1回につき1回だけです
* **詰め方は毎回同じルールで決める**：詰める順番と配置はAIに任せず、アプリ側の決まったルールで計算します。同じ買い物なら、何度やっても同じ詰め方になります

## 開発技術
### 活用した技術
#### API・データ
* Claude（画像からのレシート読み取り、商品のサイズ・重さ・性質の推定。claude.ai の Artifact の機能経由で呼び出し）
* Google Fonts（Dela Gothic One、Zen Kaku Gothic New、IBM Plex Mono）

#### フレームワーク・ライブラリ・モジュール
* Three.js r128（3D表示）
* Canvas API（写真の切り抜き・白黒化・縮小）
* HTML / CSS / JavaScript（フレームワークなし）
* PowerShell（分割したソースを、公開用の1つのHTMLにまとめるビルド）

#### デバイス
* スマートフォン・PCのWebブラウザ

### 独自技術
#### ハッカソンで開発した独自機能・技術
* **袋詰めの計算**（[src/js/packing.js](src/js/packing.js)）：袋の底をマス目に区切り、各マスの高さを記録しながら、商品を一番低く収まる位置と向きに置いていく方式です。そこに袋詰めのルールを組み合わせています
  * 重い物・立てる物 → 箱物 → 軽い物 → つぶれやすい物の順に置く
  * 紙パックなど立てる物は、横に寝かせない
  * 柔らかい物・つぶれやすい物の上には、形が変わる重さを絶対に載せない（商品ごとに「上に載せてよい重さ」の上限を持ち、積み重ねるたびに残りを減らしていく）
  * なるべくレシートの下の方（かごの上の方）にある商品から入れる。ただし上のルールを優先する
  * 袋の耐荷重を超えたら次の袋へ回す
  * 日用品は食品と別の袋にする
* **レシート写真の前処理**（[src/js/image-prep.js](src/js/image-prep.js)）：まず、大津の二値化という方法で白い用紙の範囲を自動で見つけて切り抜きます。次に、暗い側・明るい側それぞれ2%を基準に濃淡を引き伸ばし、かすれた感熱紙の文字を読みやすくします。最後に、文字が読める幅（720px）まで縮小します
* **短い返答形式**（[src/js/ai.js](src/js/ai.js)）：AIには1商品を `["卵10個パック",1,26,11,7,0.65,"b","F","c","",1]` のような配列で返させます。アプリ側でそれを元の形に戻します
* **3Dの手順再生**（[src/js/scene3d.js](src/js/scene3d.js)）：レジ袋（持ち手と、詰めてよい高さの線付き）と、フタの開いた段ボールを描き分けています。手順ごとに商品を上から落として見せます

## 動かし方
* `src/index.html` をブラウザで開くと、サンプルの買い物で3D表示と詰め直しを試せます
* レシートの読み取りは、claude.ai 上で公開したページでのみ動きます
* 公開用の1ファイルは `pwsh ./build.ps1` で `dist/fukurozume.html` に書き出されます
* ファイル構成と開発方法は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください
